## Why Nomos?

**Headline**\
Stop Rebuilding the Wheel. Start Building Your App.

**Subheadline**\
We provide the boring stuff—authentication, roles, and project structure—so you can focus on your business logic.

### Feature Grid

**Fastify Powered**\
Built on one of the fastest web frameworks in the Node.js ecosystem. High performance with low overhead.

**Astro Frontend**\
Leverage the power of Astro for a lightweight, highly performant administrative interface.

**Type-Safe End-to-End**\
Written in TypeScript. Enjoy full type safety across your API and frontend for a superior developer experience.

**Batteries Included**\
Authentication, session management, and Role-Based Access Control (RBAC) are pre-configured and ready to use.

**OpenAPI Ready**\
Your API documentation is automatically generated. Documentation lives where your code lives.

**Convention Over Configuration**\
A structured environment that makes decisions for you, reducing decision fatigue and enforcing best practices.
